## 发现层性能优化(响应更快)

`s2s_message` / `s2s_resume` / `s2s_peers` / `s2s_sessions` 的会话枚举不再逐会话**串行**读标题:

- **有界并发**(上限 8):标题读取 / 日志扫描从 O(N) 串行改为并发,保持输出顺序。
- **精确 session_id 快路径**:按 id 点名只读该会话标题(1 次,而非 N 次)。
- **in-flight 合并**:同一时刻并发进入的枚举共享同一次扫描。
- **不缓存标题**:保持「标题现读最新、改名即刻生效」的既有语义。

不含模型侧延迟(智能判官 LLM 调用 / 对方回合推理)。
